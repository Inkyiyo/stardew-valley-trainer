## 一、这是什么

一个跑在 [SMAPI](https://smapi.io/) 上的**实时修改器**：游戏内按 `F5` 呼出悬浮菜单，
直接修改正在运行的游戏数据——体力、金钱、移速、时间、天气、物品、工具、配偶……

它和「存档编辑器」的区别：

| | 存档编辑器 | 本修改器 |
|---|---|---|
| 什么时候能改 | 退出游戏后改文件 | 游戏运行中随时改 |
| 生效速度 | 重新读档才生效 | 立刻生效 |
| 能看到效果 | 看不到 | 边玩边看 |
| 风险 | 改坏了存档 | 改坏了退出不存档就行 |

它不改存档文件，只改内存。游戏自己存档的时候才会写进去（见[第七节](#七改动什么时候保存)）。

## 二、安装

### 2.1 装前置 SMAPI（只需一次）

1. 解压 `前置SMAPI\SMAPI-4.5.2-installer.zip`
2. 双击里面的 **`install on Windows.bat`**
3. 窗口里输入 `1`（Install），回车
4. 等它跑完，看到成功提示后关掉

> ⚠ SMAPI 是**框架**，不是普通 Mod，不能用拖的。必须用它的安装器装到游戏根目录。
> 装好后游戏目录里会多出 `StardewModdingAPI.exe`、`Mods` 文件夹、`smapi-internal` 文件夹。

### 2.2 装修改器

把 `StardewTrainer` **整个文件夹**拖进：

```
<你的星露谷目录>\Mods\
```

装好后目录结构应该是这样：

```
Stardew Valley\
├── StardewModdingAPI.exe          ← 2.1 装的
├── smapi-internal\                ← 2.1 装的
├── Mods\
│   ├── ConsoleCommands\           ← 2.1 自带的
│   ├── SaveBackup\                ← 2.1 自带的
│   └── StardewTrainer\            ← 2.2 拖进来的
│       ├── StardewTrainer.dll
│       ├── manifest.json
│       ├── config.json
│       ├── 使用说明.txt
│       └── i18n\
│           └── default.json
├── Stardew Valley.exe
└── ...
```

> **`i18n` 文件夹必须一起放进去。** 少了它修改器会读不到文案，
> 界面上所有字都会变成 `row.money` 这种键名。
>
> 如果 `Mods` 文件夹不存在，自己新建一个，**名字必须正好是 `Mods`**（大小写敏感）。

## 三、启动游戏

**必须用 SMAPI 启动才会加载修改器。**

### 推荐：设置 Steam 启动选项（一次设置，以后正常点「开始游戏」）

1. Steam 库 → 右键「星露谷物语」→ **属性**
2. 左侧选 **通用** → 找到「启动选项」
3. 填入下面这行（**路径换成你自己的安装目录**，注意两边的引号）：

```
"D:\steam\steamapps\common\Stardew Valley\StardewModdingAPI.exe" %command%
```

设好之后，从 Steam 启动仍然计入游戏时长、解锁成就、支持云存档。

### 备选：直接双击

双击游戏目录里的 `StardewModdingAPI.exe`。

### 怎么确认加载成功了

启动后会多一个**黑色控制台窗口**（那是 SMAPI 本体，**不要关掉**）。
滚到加载信息那里，能看到类似这样的行就说明成功了：

```
Loaded 3 mods:
   ConsoleCommands 4.5.2
   SaveBackup 4.5.2
   Stardew Trainer 1.6.0 by Stardew Trainer
```

## 四、界面与操作

进入存档后按 **`F5`** 呼出菜单。菜单打开时**游戏会暂停**。

```
┌────────────────────────────────────────────────────────┐
│  星露谷修改器                                    v1.6.0 │
├────────┬──────┬────────┬────────┬────────┤
│  角色  │ NPC  │  环境  │  物品  │  关于  │   ← 标签页
├────────┴──────┴────────┴────────┴────────┤
│  ── 状态 ──                                             │
│  日期 / 时间        第 2 年 夏季 19 日  09:00           │
│  金钱                                          1,009,500│
│  ── 一键采集 ──                                         │
│  一键采集（树 / 石头 / 矿石 / 杂草 / 树枝）    执行 ▶   │
│  ▸ 当前地图可采集      树 193 · 大障碍 39 · 石头杂草 1079│
├────────────────────────────────────────────────────────┤
│  1/22   ↑↓ 选择  ←→ 调节  Q/E 换页  回车 执行  F5 关闭 │
└────────────────────────────────────────────────────────┘
```

### 按键

| 按键 | 作用 |
|---|---|
| `Q` / `E`（或 `Shift`、`Tab`） | 切换标签页 |
| 鼠标点标签 | 直接跳到那一页 |
| `↑` `↓`（或 `W` `S`） | 上下选择 |
| `←` `→`（或 `A` `D`） | 调节数值 / 切换开关 |
| **长按** `←` `→` | 连续快速调节（按住约 0.4 秒后开始重复，越按越快） |
| `回车` | 执行 / 切换 |
| 鼠标滚轮 | 上下一行一行翻 |
| 鼠标左键 | 点选项选中；对已选中的项再点一次＝执行 |
| `F5` / `Esc` | 关闭菜单 |

### 菜单外的快捷键

| 按键 | 作用 |
|---|---|
| `F5` | 呼出 / 关闭菜单 |
| `F6` | 无限体力 开/关 |
| `F7` | 无限生命 开/关 |
| `F8` / `F9` | 移动速度 +0.1× / −0.1× |

想改键：编辑 `Mods\StardewTrainer\config.json`：

```json
{
  "MenuKey": "F5",
  "InfiniteStaminaKey": "F6",
  "InfiniteHealthKey": "F7",
  "SpeedUpKey": "F8",
  "SpeedDownKey": "F9",
  "SpeedStep": 0.1,
  "MaxSpeedMultiplier": 10
}
```

### 行的类型

菜单里每一行有三种形态，看右边的值就知道能不能按 `←→`：

| 右边显示 | 含义 | 操作 |
|---|---|---|
| `[ 开 ]` / `[ 关 ]` | 开关 | `回车` 或 `←→` 切换 |
| `×2.00`、`85%`、`第 2 年` | 数值 | `←→` 调，可长按 |
| `执行 ▶` | 一次性动作 | `回车` |
| 无（只是文字） | 只读信息 | 不能选 |

底部会显示操作结果，例如「砍树 193 棵，清大障碍 39 个…」，几秒后消失。

## 五、功能详解

### 角色页

#### 状态面板（只读）

角色名与农场名、日期时间、体力生命、金钱、移速、坐标、配偶。
**排查问题就看这里**，数值对不对一眼能看出来。

#### 生存

| 项 | 说明 |
|---|---|
| 无限体力 | 每帧把体力锁在满值。和「体力填充比例」是两个独立的东西 |
| 无限生命 | 同上，锁血量 |
| 体力填充比例 | 自动把体力补到这个百分比（0 = 关闭） |
| 生命填充比例 | 同上 |

> 「无限体力」关不掉的问题在 v1.1 已修复——现在开关和填充比例是分开的，
> 默认填充比例是 0%，不会再盖过开关。

#### 移动

| 项 | 说明 |
|---|---|
| 移动速度倍率 | 1.00–10.00×。走游戏的 buff 通道，**不会和食物加速打架** |
| 速度重置为原速 | 一键回到 1.00× |
| 工具瞬间蓄力 | 锄头/喷壶等工具不用蓄力，直接满力 |

> 移速是**绝对速度**覆盖，不是叠加。所以吃咖啡之后再调倍率，以倍率为准。

#### 工具 / 钓鱼

| 项 | 说明 |
|---|---|
| **无限浇水器** | **必须手持喷壶才有效**，水量永远满 |
| 钓鱼瞬间咬钩 | 抛竿后立刻咬钩，不用等 |
| 钓鱼瞬间捕获 | 鱼咬钩、出现收杆小游戏时，进度条直接拉满 |
| 钓鱼难度归零 | 鱼不动、条不抖。想自己玩但不想太难时用 |

#### 技能 / 幸运

- **目标等级** + **应用到全部技能**：耕种 / 钓鱼 / 采集 / 采矿 / 战斗 一次设成同一等级
- 下面五行实时显示当前各技能等级
- **幸运等级拉满**：加幸运 buff
- **幸运等级**：buff 的强度（1–50）

#### 金钱

加 1 万 / 10 万 / 100 万、按步长加减、拉满 20 亿。
步长可以自己调（1 万–1000 万）。

> 支持**降低**金钱。存档里钱多到离谱（比如溢出成负数）时也能改回来。

#### 一键采集 ★

**一次清掉当前地图上的：**

- 树木（含树苗、树桩）
- 大石头、大树桩、原木、陨石
- 石头、各种矿石、晶球
- 杂草、树枝

操作步骤：

1. 看「当前地图可采集」那一行，先知道有多少东西
2. 按 `回车` 执行「一键采集」
3. 底部会显示实际清了多少：`采集完成：砍树 193 棵，清大障碍 39 个，清石头杂草 1079 个`

**几个要点：**

- **掉落是游戏正常给的**——木材、石头、矿石、纤维、树液都会进背包或掉在地上，
  不是凭空删除
- **不会动庄稼**。种在地里的东西、箱子、已放置的物品都不碰
- **只作用于当前地图**。想清农场就站在农场里点
- 可以重复点，第二次会报 0，不会报错
- 也能分开用：只砍树 / 只清石头杂草 / 只清大障碍

> ⚠ **这是破坏性操作**，地图上的树和杂物会没掉。
> 建议先睡一觉存档，不满意就退出不存档。
> 想恢复的话，退出游戏后把 `%APPDATA%\StardewValley\Saves\` 里的存档备份换回来。

#### 获取全部工具 ★

一次拿到整套工具（已有的会自动跳过，不占背包）：

- **基础**：斧头、十字镐、锄头、喷壶、挤奶桶、剪刀
- **鱼竿 5 种**：训练用鱼竿 → 竹鱼竿 → 玻璃纤维棒 → 铱金鱼竿 → 高级铱金鱼竿
- **淘金盘 4 种**：铜 / 钢 / 金 / 铱
- **实用**：灯笼、回程魔杖

> 为什么没有镰刀？1.6 的游戏数据表里镰刀不是「可获取物品」（游戏开局就送、
> 且无法作为道具给予），所以给不了。给个错的 ID 反而会变成「错误物品」。

#### 传送

调好 X / Y，按「传送到目标格」。也可以先把当前位置读进来再微调。

### NPC 页

#### 好感度

- **所有 NPC 好感度拉满**：把所有认识的人（有友谊数据的人）一次拉满到 2500 点
- 已离异的不动，避免把关系状态搞乱

#### 宠物 / 农场动物 ★

| 项 | 说明 |
|---|---|
| 宠物好感度拉满 | 猫、狗等宠物，拉到游戏的 `maxFriendship` |
| 农场动物快乐度拉满 | 所有牲畜的 happiness → 255 |
| 农场动物饱足度拉满 | 所有牲畜的 fullness → 255（等于喂饱） |

这一页会显示当前宠物数量和农场动物数量，方便确认有没有生效。

> 动物必须在某个有动物列表的地图里（畜棚/鸡舍内部）才会被扫到。
> 站在农场里点通常也能覆盖到。

#### 配偶 / 结婚 ★

**可以把任意 NPC 设成老婆/老公**，包括矮人、科罗布斯这种非村民。

1. 用 `←→` 在「选择的 NPC」那一行挑人（旁边会显示当前关系）
2. `回车` 执行「把『选择的 NPC』设为老婆 / 老公」

**行为：**

- 好感度自动拉满，关系状态设为已婚
- **换人时上一任自动解除**——上一任状态改为「离异」，不会出现两个配偶
- **自动把房子升到 1 级**

> 为什么要升房子？游戏的 `FarmHouse.updateMap()` 在「有配偶」时会去找
> `Maps\FarmHouse{升级等级}_marriage` 这张地图。升级等级 0 对应的
> `FarmHouse_marriage` **根本不存在**（只有 `FarmHouse1_marriage` / `FarmHouse2_marriage`），
> 所以结婚后每次进农舍都会报 `ContentLoadException`。升到 1 级就对上了。

快捷项「把艾比盖尔 Abigail 设为老婆」是固定按钮，方便反复测试。

#### 生成 NPC / 怪物

- **生成的村民**：29 个村民可选，在身旁生成。如果该 NPC 已经在世界里，会改成传送到你身边（避免出现两个同名 NPC 导致社交面板冲突）
- **传送 NPC**：把「选择的 NPC」拉到你身边
- **删除修改器生成的角色**：清理测试留下的 NPC
- **怪物**：20 种怪物，在身旁生成
- **一击必杀**、**立即清空全场怪物**、**怪物不刷新**（最后这个要重进地图才生效）

> 测试用的 NPC 和怪物**不会**自动保存进存档——除非你主动存盘。

### 环境页

#### 天气

晴天 / 雨天 / 雷雨 / 下雪 / 大风落叶 / 绿雨，可选**是否连明天一起改**。
也可以直接点「直接改成：雨天」这种快捷项。

> 改天气只改天气标记，不去碰游戏的雨滴/落叶数组
> （早期版本直接操作那些数组会引发 `IndexOutOfRangeException` 崩在 base update loop）。

#### 时间

| 项 | 说明 |
|---|---|
| 当前时间 | 只读 |
| 设定：小时 / 分钟 | 目标时间，分钟按 10 分钟一档 |
| 把时间设为上面的「时:分」 | 跳到设定时间 |
| 每次调整的分钟数 | 快进步长（10–120 分钟） |
| 时间 + / − 步长 | 按步长快进或回退 |
| 跳到 06:00 / 12:00 / 18:00 / 22:00 / 24:00 | 常用时间点一键跳 |
| 时间静止 | 时间不再走 |
| 时间流速倍率 | 0.5×–10× |

**两个限制（游戏本身的机制）：**

- 游戏内部时间只有 **10 分钟粒度**，所以分钟会自动对齐到 10 的倍数
- 凌晨 2:00 之后进入「昏倒结算」，硬跳过去会破坏当天状态，
  所以回退/跨天**最多夹在 26:00**

#### 日期

年 / 季节 / 日分别调，然后「把日期设为上面的年/季/日」。
日期显示成完整写法，例如 **「第 2 年 夏季 17 日」**，不再是一串看不懂的数字。

#### 其它

- **立刻保存游戏**：等于走一次游戏的保存流程（会看到保存进度条）
- 提示行说明改动何时落盘

### 物品页

- **选择的物品** + **数量** → 「获取…× 数量」
- 「下一个物品」快速轮换
- 下面列出 36 种常用物品，每行点一次拿 1 个

常用物品包括：钻石、五彩碎片、各类宝石、金属锭（铜/铁/金/铱）、精炼石英、电池组、
布料、硬木、木材、石头、果酒、啤酒、淡啤酒、恐龙蛋、星之果实、万象晶球、仙尘、齐钻、
金色核桃、金蛋、各类种子（上古/甜瓜/南瓜/杨桃/向日葵/防风草/玫瑰仙子）等。

> **每个 ID 都用游戏自己的数据反查核对过**，菜单显示的名字就是你实际拿到的东西。

> 早期版本这里有 11 个 ID 是错的（比如「铜锭」给的是铁锭、金锭其实是铱锭），v1.6 已全部修正。
>
> 想要列表之外的东西，用控制台：先 `trainer_finditem <关键词>` 查准确 ID，
> 再 `trainer_item <ID> <数量>`。

## 六、控制台命令

在 SMAPI 的黑色控制台窗口里直接输入，回车执行。

### 状态与排查

| 命令 | 说明 |
|---|---|
| `trainer` | 打开菜单 |
| `trainer_debug` | **打印当前所有状态和游戏里的实际数值**，排错第一步 |
| `trainer_tab NPC` | 打开菜单并切到指定页（角色/NPC/环境/物品/关于） |
| `trainer_itemcheck` | 核对物品表（菜单名 vs 游戏实际名） |
| `trainer_toolcheck` | 核对工具表 |
| `trainer_harvestinfo` | 看当前地图有多少可采集物 |
| `trainer_debrisinfo` | 把判定为「杂物」的对象按名字分组统计 |

### 数值

| 命令 | 说明 |
|---|---|
| `trainer_money 500000` | 设置金钱 |
| `trainer_speed 3` | 移动速度 3 倍（1 = 原速） |
| `trainer_water 1` | 无限浇水器开（0 = 关） |
| `trainer_fishing 1` | 钓鱼三项全开（0 = 全关；不带参数看当前状态） |

### 采集与工具

| 命令 | 说明 |
|---|---|
| `trainer_cut` | 砍掉当前地图所有树 |
| `trainer_cut clump` | 只清大石头 / 大树桩 / 原木 |
| `trainer_cut all` | 一键采集（树 + 大障碍 + 石头杂草） |
| `trainer_tools` | 获取全部工具 |

### 时间与天气

| 命令 | 说明 |
|---|---|
| `trainer_time 1800` | 时间设为 18:00（`trainer_time 6:30` 也认） |
| `trainer_date 2 1 15` | 日期设为第 2 年夏季 15 日（年 季 日，季用 1–4） |

## 七、改动什么时候保存

**修改器只改内存。**

游戏自己存档的时候才会写进存档文件。三种触发方式：

1. **睡觉过夜**（最常规）
2. **游戏菜单 → 退出到标题**
3. **环境页点「立刻保存游戏」**，或控制台 `trainer_save`

所以：

- 改坏了 → **直接关掉游戏**（Alt+F4 / 任务管理器），改动全部丢弃
- 改好了 → 存一次盘

SMAPI 自带 **SaveBackup** 模组，会自动把每天的存档备份一份到
`%APPDATA%\StardewValley\Saves\` 下的 `_backup_*` 目录，多一层保险。

## 八、换语言 / 翻译

界面上**每一个字**都在 `Mods\StardewTrainer\i18n\default.json` 里（223 个键）。

结构很简单：

```json
{
  "tab.self": "角色",
  "row.money": "金钱",
  "msg.trees_cut_fmt": "砍掉了 {0} 棵树（木材等掉落已进背包）"
}
```

### 翻译步骤

1. 复制 `default.json`，改名成语言代码
   - `en.json`（英文）、`ja.json`（日文）、`ko.json`（韩文）……
   - 名字跟游戏语言代码对应
2. **只改右边的值**，左边的键一个字都不要动
3. 放回同一个 `i18n` 文件夹
4. 重启游戏

### 加载规则

```
i18n/<游戏语言>.json  →  i18n/default.json  →  键名本身
```

- 你的语言文件缺哪个键，就自动回落到中文，**不会出现空白**
- 连 `default.json` 都缺，才显示键名（这时一眼能看出来漏翻了什么）

### 占位符

`{0}`、`{1}`、`{2}` 是运行时填入的值（数量、时间等）。翻译时**保留它们的顺序**就行，
位置可以调。例如：

```json
"msg.trees_cut_fmt": "{0} trees cut down"
```

翻译错了（比如写了个 `{99}`）也不会崩，会原样显示模板本身。

## 九、常见问题

### 按 F5 没反应

1. 确认是用 `StardewModdingAPI.exe` 启动的（不是直接点 Steam「开始游戏」）
2. 确认**已经进入存档**——在标题界面按 F5 不响应是故意的
3. 看控制台窗口里有没有 `Stardew Trainer 1.6.0` 这一行

### 控制台里看不到 Stardew Trainer

- 路径必须是 `Mods\StardewTrainer\StardewTrainer.dll`
  - ❌ `Mods\StardewTrainer.dll`（少了文件夹）
  - ❌ `Mods\StardewTrainer\StardewTrainer\...`（多套了一层）
- `manifest.json` 和 `i18n` 文件夹要一起在

### 界面上显示的是 row.money 这种键名

`i18n` 文件夹没放进去，或者 `default.json` 坏了。
把压缩包里的 `i18n` 文件夹整个拷过来。

### 从 Steam 点开始游戏没有修改器

启动选项没设置。见[第三节](#三启动游戏)。

### 一键采集会不会铲了我的庄稼？

不会。只清树、石头、矿石、杂草、树枝、大障碍。庄稼、箱子、已放置物品都不动。

### 一键采集的掉落去哪了？

走游戏自己的采集逻辑，木材/石头/矿石/纤维正常进背包或掉在地上。
如果背包满了，会掉在脚下。

### 工具列表里为什么没有镰刀？

1.6 的数据表里镰刀不是可获取物品（开局就送、无法作为道具给予）。
硬给一个不存在的 ID 只会得到「错误物品」。

### 无限浇水器没用

要先**手持喷壶**（快捷栏选中）。拿着斧头或空手时这个开关不生效。

### 钓鱼瞬间捕获没反应

这个开关作用在**收杆小游戏**上——鱼咬钩、出现那条竖着的界面时才会立刻拉满。
抛竿阶段用的是「瞬间咬钩」。

### 设了配偶之后进农舍报错

v1.3 已修复（会自动把房子升到 1 级）。换成本压缩包里的 dll。

### 无限体力关不掉 / 速度改了没反应 / 控制台刷音频报错

都是 v1.0 的 bug，v1.1 起已修复：

- 无限体力关不掉 → 开关和填充比例分离
- 速度没反应 → 改成走 buff 通道（直接写 `addedSpeed` 会被 buff 系统每帧覆盖）
- 音频报错 → 早期用了不存在的音效名，已改用真实音效

### 菜单里的版本号不对

v1.4 起从 manifest 读取，不会写死。「关于」页可以看到。

### 想看日志

```
%APPDATA%\StardewValley\ErrorLogs\SMAPI-latest.txt
```

遇到问题先跑 `trainer_debug`，再把日志这段贴出来。

### 游戏更新后修改器报错

游戏大版本更新后需要重新编译。仓库里有源码，按 README 的说明自己编，
或者等更新。
